API

File JSON statis di GitHub Pages. Tidak perlu daftar, dan bisa dipanggil langsung dari browser.

curl https://khrlanamm.github.io/buku-indonesia/api/v1/isbn/9789799731234.json
EndpointIsi
api/v1/isbn/{isbn}.jsonSatu buku, dari ISBN-13 atau ISBN-10
api/v1/books/{id}.jsonSatu buku, dari ID
api/v1/authors.jsonSemua penulis dan jumlah bukunya
api/v1/authors/{slug}.jsonBuku satu penulis
api/v1/categories.jsonSemua kategori
api/v1/categories/{slug}.jsonBuku satu kategori
api/v1/stats.jsonAngka ringkas katalog

Unduh data

Seluruh katalog dalam satu file, bebas dipakai untuk apa saja.

  • books.csvuntuk spreadsheet dan analisis
  • books.jsonuntuk aplikasi dan skrip
  • books.sqliteuntuk aplikasi offline

Bantu lengkapi

Katalog ini jauh dari lengkap. Perpusnas mencatat lebih dari 728 ribu ISBN sampai 2023. Kalau ada buku yang belum masuk atau datanya keliru, kabari lewat formulir, atau kirim pull request kalau kamu developer.
